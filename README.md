# Shadn’s Learning Hub — Stage 1 (Foundation)

Free, static site: HTML, CSS and vanilla JavaScript. No backend, no paid services, no API keys.

## What works now (Stages 1-6, early)
- Pronunciation lab (British, American, German), translation practice with model answers and rubric, reading and listening library (2 original texts), courses directory (12 verified providers, no prices), progress page with achievements
- German A1: 3 complete lessons (alphabet, greetings, gender) with 24 questions, same exam engine
- British English A1: 3 complete lessons with exams (8, 7, 7 questions), 80% pass mark, progressive unlocking, attempt history, retakes and an automatic Mistakes notebook with practice
- Translator (Arabic, English, German) via the free MyMemory service, with British, American and German voice buttons. A voice is played only if the device has it; otherwise a clear message is shown
- Vocabulary notebook with search, filters, flashcards and spaced repetition
- Study planner with weekly view; ticking a task logs real study time to the dashboard

- Dashboard with daily/weekly goals, streak, study hours and a weekly chart, all calculated from sessions you log
- English (LTR) and Arabic (RTL) interface, light and dark mode
- Settings: name, daily goal, JSON export/import backup, reset with confirmation
- British English, German and Alsun sections are placeholders: no lessons yet

## Publish on GitHub Pages
1. Create a new public repository on github.com (for example `shadns-learning-hub`).
2. Upload the contents of this folder (`index.html`, `css/`, `js/`, `README.md`) to the repository root.
3. Go to Settings, then Pages. Under Source choose "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
4. After a minute the site is live at `https://YOUR-USERNAME.github.io/shadns-learning-hub/`.

All paths are relative, so it works inside a repository subpath.

## Data
Progress is stored in this browser's localStorage only. Use Settings, then Export backup regularly.

## Not yet tested
